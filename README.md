# 记账宝

> 作者利用 AI 完成 Vibe Coding 的一款软件，能实时监听金额交易。

一款 Android 手机记账 App。自动识别微信、支付宝、银行的收支通知，一键记账。数据全部存在手机本地，无需联网，不上传任何信息。

---

## 📥 安装教程

### 第一步：安装 APK

将 `记账宝.apk` 传到手机上，点击安装。

> 如果提示"未知来源应用"，点 **允许** 即可。

### 第二步：开启通知使用权（必需）

App 需要监听支付通知才能自动检测收支。

```
设置 → 通知和状态栏 → 通知使用权（通知监听）
→ 找到"记账宝" → 开启 ✅
```

> **如果不开启，App 无法自动检测支付，所有功能都需要手动记账。**

### 第三步：开启悬浮窗权限（推荐）

支付检测到的交易可以浮在任意 App 上方弹出确认条。

```
设置 → 应用 → 记账宝 → 悬浮窗
→ 允许显示在其他应用上层 ✅
```

## 📖 使用说明

### 自动记账（核心功能）

**支付后**，手机会弹出通知：
> 💸 微信支付 支出 ¥35.00 — 点击记账

点击通知 → 打开记账宝 → 顶部弹出灵动岛确认条 → 点 **确认记账** 即可。

支持自动识别的 App：

| App | 能检测什么 |
|-----|-----------|
| 微信 | 支付、收款、转账、红包 |
| 支付宝 | 支出、收款、转账 |
| 招商/工商/建设/农业/中国/交通/邮储银行 | 消费、存入、扣款、快捷支付 |
| 云闪付 | 消费、存入 |

### 手动记账

首页 → 点右下角 **+** 按钮 → 填写金额、选择分类/来源 → 保存。

### 常驻快捷入口

通知栏常驻一条通知：
> 记账宝 点击 + 快速记一笔

下拉通知栏，点 **记一笔** 即可快速打开记账页面。

### 月度统计

底部切换到 **统计** 页，查看当月收入/支出/结余，以及支出分类排行。

### 数据管理

底部切换到 **我的** → 清除所有数据（注意：不可恢复）

### 调试日志

**我的** → 展开 **调试日志**，可查看通知监听的原始记录。如果某笔交易没检测到，从这里看原文可以帮我修复。

## 🔧 常见问题

**Q：支付后没有弹出通知？**

A：先检查两步：
1. **通知使用权**是否开启（设置 → 通知使用权 → 记账宝）
2. **App 的通知权限**是否开启（设置 → 应用 → 记账宝 → 通知 → 允许）

**Q：微信转账金额显示为 0？**

A：微信转账通知不包含金额信息，这是微信的限制。灵动岛会自动展开，你手动输入金额后确认即可。

**Q：银行活动通知被当成交易了？**

A：部分银行的广告、促销、复盘通知也带有金额字样。已做过滤，如果还有遗漏的，把调试日志发给我修复。

**Q：数据会丢吗？**

A：数据存在手机本地（localStorage）。卸载 App 会清除数据。建议定期手动记下重要流水。

## 🔒 隐私说明

- 所有数据仅存手机本地
- 通知监听仅在手机本地处理，不联网、不上传
- 只解析含金额关键词的通知，普通聊天/广告不处理
- 清除数据时备份一并删除，不可恢复
